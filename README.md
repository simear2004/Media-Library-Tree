# Media-Library-Tree

A lightweight media library tree script based on the foo_uie_jsplitter component on the foobar2000 player. It uses a folder structure to display the directory tree. It supports tree hierarchy, instant search, hierarchical expansion/collapse, sending to a specified list and locating the currently playing item.

foobar2000 播放器上基于 foo_uie_jsplitter 组件的轻量化媒体库树脚本，采用文件夹结构展示目录树，支持树层级、即时搜索、层级展开/折叠、发送到指定列表和定位到正在播放的项目
