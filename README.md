# A lightweight media library tree script based on the foo_uie_jsplitter component on the foobar2000 player

A lightweight media library tree script based on the foo_uie_jsplitter component on the foobar2000 player. It uses a folder structure to display the directory tree. It supports tree hierarchy, instant search, hierarchical expansion/collapse, sending to a specified list and locating the item being played. It supports the font system and color system of the default user interface, and supports system scaling.

How to use:   
1. First install the foo_uie_jsplitter component: https://github.com/dima-lur/jsplitter  
2. Add a jsplitter panel and import the MLTree.js file.
